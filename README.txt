PROJETO KOTLIN + POSTGRESQL

1. Crie o banco PostgreSQL chamado: caixaDaAgua
2. Execute o arquivo: sql/schema.sql
3. Confira usuário e senha em: src/repositorio/ConexaoPostgres.kt
4. Adicione o driver JDBC do PostgreSQL ao projeto.
5. Execute: src/main/kotlin/Main.kt

Observação: o código que já estava funcional foi mantido sempre que possível.
Foram corrigidos apenas pontos que impediam compilação/execução e adicionados
os requisitos que ainda não existiam no projeto.
